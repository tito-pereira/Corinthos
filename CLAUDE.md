# Corinthos contributor guidance

Follow [AGENTS.md](AGENTS.md) and the selected project's local skills. The backend provides workspace, process, continuity and Update infrastructure; skills govern engineering work. Use the explicit project root and declared write scopes. Preserve user content, isolate outputs and independently review changes before integration. Never treat a successful provider exit as product acceptance.

Current commands and operational limits are documented in [README.md](README.md), [GUI guide](docs/gui.md) and [backend operations](docs/backend.md). No legacy Engine/Contract workflow remains active. Controlled process and actual desktop evidence do not establish live provider correctness.
