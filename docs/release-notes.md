# Prototype runtime and GUI development snapshot

The prototype workspace/17 local skills and generic isolated Python execution replace the former Engines, governance contracts and governed context machinery. Shared installation, signed compatible-format Update, runtime exclusion, recovery and native health remain.

The new two-page GUI adds reference-based branding, real Main/project conversations, actual skill-backed staged project creation, preserving working-copy import, recent-project resumption, read-only ideas/task summaries and explicit local orchestrator execution. Run actions remain bound to their original project and expose Apply/Discard/Cancel without treating process success as applied work.

Long preparation/copy/integration/provider work runs outside the serialized request handler; bounded operation/output projections keep status observable. Project metadata and context persist independently of compact navigation hints. Obsolete Engine-view components, bridge assumptions and observer behavior are replaced rather than reactivated.

Legacy state remains preserved/refused without automatic migration. Verification records distinguish controlled providers, actual desktop/visual observations and live-provider evidence. No production release or real-user installation replacement is published by this source change.
