# Create Project

## Workflow
1. Create a "repo" folder (if it doesn't exist already).
2. Create a "context_agents" folder (if it doesn't exist already).
3. Create a "context" folder (if it doesn't exist already).
4. Inside the "context" folder, create "PROJECT.md", "DECISIONS.md", "ARCHITECTURE.md" and "CURRENT_STATE.md" (if they don't exist already).
5. Create a "task_agents" folder (if it doesn't exist already).
6. Create a "task" folder (if it doesn't exist already).
7. Inside the "task" folder, create "implementation-groups.md" (if it doesn't exist already).
