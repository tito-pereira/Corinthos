# Analyze Architecture

## Usage
1. This will be a support skill. Its purpose is to learn and create more context about the project to serve as support to other skills or to the User.

## Workflow
1. Study, learn and analyze the current project's repository inside the "repo" folder.
2. Study, learn and analyze the current project's context inside the "context" folder.
3. If another skill calls this skill, pass the learned and analyzed context to it.
4. If the User calls this skill, report back the analysis, observations and global opinion back to the User.
