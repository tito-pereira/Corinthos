# Create Steps List

## Workflow
1. You will receive an integer corresponding to the implementation group you will translate into sequential technical implementation steps.
2. Study, learn and analyze the corresponding group's planned new features in "task/implementation-groups.md", according to the integer you received.
3. Define separate, clear and sequential implementation steps.
4. There will be a folder "task/task_?", with "?" corresponding to the integer you received. Write down your list of steps in "task/task_?/implementation-steps.md".
5. For each step, put a "checked/unchecked" option for future reference to guide what's already implemented or not.
6. Report back to the User or caller skill the number of steps, a brief description on all of them, and flag unresolved dependencies.
