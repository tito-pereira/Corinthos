# Create Feature

## Workflow
1. You will receive a number from your caller skill agent.
2. In "task/task_?/implementation-steps.md", with "?" being the number you received, look for the next unchecked or the next not implemented feature.
3. In case of uncertainty or lack of information, check for all the implementation steps and use $analyze-architecture to see what steps have actually been made and what is the next one in line.
4. Interpret and convert that implementation step into technical software tasks.
5. Write the prompt for the execution of those technical software tasks, in order, into "task/task_?/task-description.md", with "?" being the number you received.
