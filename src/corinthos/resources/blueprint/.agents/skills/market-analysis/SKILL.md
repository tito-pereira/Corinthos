# Market Analysis

## Usage
1. This will be a support skill. Its purpose is to learn and create more context about the project to serve as support to other skills or to the User.

## Workflow
1. Search the Internet for companies, products and repositories of the same market or functionality of the current project's product.
2. If insight about the current project is needed, use $analyze-architecture.
3. Focus on a maximum of the 20 biggest competitors, and study and analyze exactly how they compare to the project's product: what they do better, what they do worse, what they do similarly, what they do differently.
4. If another skill calls this skill, pass the learned and analyzed context to it.
5. If the User calls this skill, report back the analysis, observations and global opinion back to the User.
